# Revit add-in {#revit_addin}

`DxfToRevit.Addin` targets Revit 2025 (.NET 8). It compiles the `DxfToRevit.Revit` sources with
`REVIT_API_AVAILABLE`, so the adapter runs against the real Revit API.

## Ribbon

`DxfToRevitApplication` creates the **DxfToRevit** tab with the **DXF Import** panel:

| Button | Command | Purpose |
|--------|---------|---------|
| Import DXF | `ImportDxfCommand` | Imports walls and columns from a DXF file |
| Column Settings | `ColumnSettingsCommand` | Opens the settings dialog on its own (choose options, load families) |
| About | `AboutCommand` | Short description |

Icons exist in light and dark variants (`Resources/<Name>_<Light|Dark>_<16|32>.png`). The current
Revit theme is read at start-up and the icons are swapped when the `ThemeChanged` event fires.
The icons are generated by `scripts/IconGenerator`.

## Import settings

`ColumnImportSettingsForm` collects:

- **Base Level** and **Top Constraint** (a level above the base, or *Unconnected*);
- **Unconnected Height** (only when the top constraint is *Unconnected*);
- **Circular columns** mode and family type (see @ref columns);
- **Other columns**: whether to import freeform columns and whether to build them as families.

Choices are remembered for the Revit session (`ColumnImportPreferences`).

## Import flow

1. Settings dialog, then DXF file selection.
2. `DxfCenterLinePipeline.Analyze` (no files are written next to the DXF).
3. Requests are built with the session options: wall types by thickness, column kinds and keys.
4. `BuildingModelService` validates the requests and calls `RevitWallCreator` /
   `RevitColumnCreator`, which delegate to `RevitApiDocumentContext`.
5. Every element is created in its own transaction inside one `TransactionGroup`. The group is
   assimilated into a single undo step, or rolled back when nothing could be created.
6. A summary dialog shows counts, skipped ambiguous face pairs, grouped failures and notes.

### Walls

Basic Walls are created on the base level with the unconnected height and base offset; with a
top level, the Top Constraint is set to it. Wall types are found by thickness in the requested
family (`Basic Wall` by default); when no type matches, a type is duplicated and its widest layer
resized (`RevitElementResolver.ResolveWallType`).

## Deployment

Building the add-in copies the DLLs, the icons and `DxfToRevit.addin` to
`%APPDATA%\Autodesk\Revit\Addins\2025`. Build while Revit is closed (the DLL is locked otherwise).
Override the destination with `-p:AddinDeployDir=<folder>` and the Revit installation with
`-p:RevitApiDir=<folder>`.

```bash
dotnet build DxfToRevit.Addin
```

For distribution to other computers, use the installer instead (see @ref installation);
build it with `-p:DeployAddin=false` so your own Revit folder is not touched.
